## Сложности и решения

При восстановлении проекта исходники лежали в корне, а в `Main.kt`
остался импорт отсутствующего `TestUtils`. Исходники разложены по
`src/main/kotlin` согласно структуре из методички. Добавлены `TestUtils`
и конфигурация Gradle, после чего точка входа снова запускается.

Хвостовая рекурсия вынесена в отдельную функцию с накопителем.
Так внешний вызов factorial сохраняет один параметр, как в условии.
Для пустого списка людей возвращается 0.0, поскольку average сам по себе
для пустого списка не возвращает требуемый результат.

Все три async создаются до ожидания. select позволяет получать уже
завершившуюся задачу, затем await получает её результат. Поэтому остальные
задачи продолжают выполняться во время ожидания, а вывод идёт по завершении.

## Что нового показывает работа

- `val` нельзя присвоить новое значение, а `var` можно. Тип `Int?` допускает `null`.
- Вызов `str?.toIntOrNull()` возвращает `null` для отсутствующей строки и для некорректного числа.
- `map` преобразует элементы, `filterNotNull` удаляет `null`, а `groupBy` собирает группы по ключу.
- `delay` приостанавливает корутину, `async` запускает задачу с результатом, а `await` получает этот результат.

## Вывод

Решения показывают основные способы обработки данных на Kotlin.
Операции над коллекциями позволяют обходиться без ручного накопления
