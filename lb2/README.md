# Kotlin Tasks — лабораторная работа №2

Консольный проект по второй лабораторной. В нём десять задач
на базовый синтаксис, null-безопасность, коллекции и корутины.

## Технологии

- Kotlin/JVM 2.2.10.
- Gradle (Kotlin DSL).
- kotlinx.coroutines 1.9.0.
- Проверки в `main()` с выводом в консоль.

## Запуск

Откройте папку проекта в IntelliJ IDEA как Gradle-проект и дождитесь
синхронизации. Запустите функцию `main()` в `Main.kt`.
В качестве Gradle JDK можно указать JDK из Android Studio
(`C:\Program Files\Android\Android Studio\jbr` при стандартной установке).
Для первой синхронизации требуется интернет.

В Windows из терминала в папке проекта:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat run
```

В Linux с настроенным JDK:

```bash
chmod +x gradlew
./gradlew run
```

Проверки выводятся в консоль. При несовпадении результата с ожидаемым
программа завершится с ошибкой. В конце успешного запуска выводится
«Все проверки пройдены». Проверка задержек занимает около пяти секунд.

## Структура

- `src/main/kotlin/Main.kt` — запуск и проверки всех задач.
- `tasks/BasicSyntax.kt` — приветствие, сезон и факториал.
- `tasks/NullSafety.kt` — безопасное преобразование и фильтрация null.
- `tasks/DataClasses.kt` — класс Person.
- `tasks/Collections.kt` — среднее, группировка и поиск слова.
- `tasks/Coroutines.kt` — задержка и параллельные задачи.
- `utils/TestUtils.kt` — сравнение ожидаемого и фактического результата.

Пути tasks и utils указаны относительно src/main/kotlin.

## Принятые правила

Факториал использует хвостовую рекурсию во вспомогательной функции.
Для отрицательного аргумента возвращается -1; для значений больше 20
выдаётся понятная ошибка, поскольку результат не помещается в Long.
Пустые строки при группировке пропускаются.
